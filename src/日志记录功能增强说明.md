# V9.5 增强日志记录功能说明

## 概述

基于V9.5系统克隆并增强了日志记录功能，新增了原始请求和响应数据的完整记录能力，便于调试和分析CGI命令执行过程。

## 增强功能

### 1. 新增日志记录方法

#### log_raw_request()
- **功能**: 记录完整的原始请求数据
- **参数**: 
  - `device_ip`: 设备IP地址
  - `command_index`: 命令序号
  - `total_commands`: 总命令数
  - `full_url`: 完整URL地址
  - `raw_command`: 原始命令字符串
  - `auth_type`: 认证方式
  - `headers`: 请求头信息
  - `method`: HTTP方法

#### log_raw_response()
- **功能**: 记录完整的原始响应数据
- **参数**:
  - `device_ip`: 设备IP地址
  - `status_code`: 状态码
  - `response_time`: 响应时间
  - `response_headers`: 响应头信息
  - `response_body`: 完整的响应内容
  - `raw_command`: 原始命令字符串

### 2. 增强现有方法

#### log_cgi_request()
- **增强**: 新增`raw_command`参数，记录原始命令
- **日志格式**: 包含完整的请求元数据和原始命令

#### log_cgi_response()
- **增强**: 新增`raw_command`参数，记录原始命令
- **增强**: 取消响应内容截断，记录完整响应
- **日志格式**: 包含完整的响应元数据和原始命令

### 3. 集成到设备管理器

在`device_manager.py`的`_send_command`方法中集成了增强的日志记录：

- **请求记录**: 同时调用`log_cgi_request`和`log_raw_request`
- **响应记录**: 同时调用`log_cgi_response`和`log_raw_response`
- **异常记录**: 所有异常情况都记录原始命令信息

## 使用说明

### 1. 直接使用日志管理器

```python
from utils.log_manager import LogManager

log_manager = LogManager()

# 记录请求
log_manager.log_cgi_request(
    device_ip="192.168.1.100", 
    command_index=1, 
    total_commands=5,
    full_url="http://192.168.1.100/cgi-bin/configManager.cgi",
    auth_type="digest",
    headers={"User-Agent": "MyApp/1.0"},
    method="GET",
    raw_command="cgi-bin/configManager.cgi?action=getConfig"
)

# 记录原始请求
log_manager.log_raw_request(
    device_ip="192.168.1.100",
    command_index=1,
    total_commands=5,
    full_url="http://192.168.1.100/cgi-bin/configManager.cgi",
    raw_command="cgi-bin/configManager.cgi?action=getConfig",
    auth_type="digest",
    headers={"User-Agent": "MyApp/1.0"},
    method="GET"
)
```

### 2. 通过设备管理器自动记录

当使用`ConfigExecutor`发送CGI命令时，系统会自动记录完整的请求和响应信息。

## 优势

1. **完整记录**: 记录原始命令和完整响应内容，便于调试
2. **便于分析**: 原始数据格式便于自动化分析和处理
3. **问题定位**: 详细的日志信息有助于快速定位问题
4. **兼容性**: 保持与现有系统的完全兼容
